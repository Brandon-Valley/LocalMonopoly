## About

LocalMonopoly is a single-page browser game built to feel like a local, map-inspired board game. It is designed to run directly in the browser with no install step, no backend, and no extra app download.

The live version is published with GitHub Pages here:

[https://brandon-valley.github.io/LocalMonopoly/](https://brandon-valley.github.io/LocalMonopoly/)

## Highlights

- Playable directly from a web browser
- Mobile-friendly GitHub Pages deployment
- Single static site setup
- Local map board-game style
- Automatic publishing through GitHub Actions

## Deployment

This repository deploys automatically with GitHub Actions on every push to `master`.

The published site is served from:

[https://brandon-valley.github.io/LocalMonopoly/](https://brandon-valley.github.io/LocalMonopoly/)
